Проект 1 (Старт): Vue 3 SPA «Задачник» без бэкенда

Цель: освоить TypeScript, Vue 3 Composition API, маршрутизацию, управление состоянием через composables,
базовое тестирование, доступность, документацию.

Технологии
Node LTS, pnpm/npm, Vite, Vue 3 + TS, Vue Router.
ESLint + Prettier (консистентный стиль).
Vitest + Vue Test Utils.
Lighthouse (проверка перфоманса/а11y).
Хранилище: localStorage (никаких бэкендов/Pinia на этом этапе).

Функциональные требования
CRUD задач: добавить, редактировать, завершать/возвращать, удалять.
Фильтры: все/активные/завершённые; поиск по названию.
Группировка по проектам/тегам (минимум один из вариантов).
Undo последнего удаления (в пределах сессии).
Сохранение состояния в localStorage.
Роуты: список задач, детали задачи по id, страница «О приложении».
Адаптивная верстка (мобильная и десктоп).
Доступность: навигация с клавиатуры, семантика, контраст, ARIA по необходимости.

Нефункциональные требования
TypeScript: без any/@ts-ignore (за редкими обоснованными исключениями).
Компоненты с чёткими пропсами/эмитами, как минимум один компонент со слотами.
Минимум 5 юнит-тестов: логика useXxx и пара рендер-тестов компонентов.
Линтинг/форматирование в CI-скриптах проекта, чистый npm run lint.
Lighthouse: Performance/Accessibility/Best Practices/SEO ≥ 90 на десктопе.
README с описанием архитектуры и решений.

Ограничения (чтобы не упростить чрезмерно)
Нельзя: UI-библиотеки (Element/Naive/Ant), глобальные стейт-менеджеры, Tailwind/Bootstrap.
Разрешено: собственные утилиты и минимальные пакеты для дат/uuid.

Структура проекта (пример)
src/app — корневые настройки приложения (инициализация, маршруты)
src/components — переиспользуемые компоненты
src/pages — страницы роутов
src/composables — логика (например, useTodos, useLocalStorage)
src/types — доменные типы
src/utils — утилиты
src/styles — глобальные стили
tests — тесты

Скрипты
dev, build, preview
lint, lint:fix
test, test:watch, опционально test:coverage

Чек-лист приёмки
Работает весь CRUD, фильтры, поиск, Undo.
Навигация по роутам без ошибок, перезагрузка страницы сохраняет состояние.
Без ошибок консоли в прод-сборке и в тестах.
Тесты зелёные, линт чистый, Lighthouse ≥ 90.
README: стек, структура, архитектура, команды, решения и trade-offs.
